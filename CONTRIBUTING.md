# Contributing

Contributions to Folio are welcome. Read [BUILDING.md](BUILDING.md) and the [license](LICENSE) before getting started.

Keep changes focused and reuse existing functionality. Describe the problem and the resulting behavior in your pull request. For interface changes, include screenshots using sample content.

Preserve original documents, compatibility with saved libraries, accessible controls, and all supported themes. Model contributions must include their source and license attribution.

Use public issues for feature requests and reproducible bugs. Do not include personal documents, credentials or account information. See [SECURITY.md](SECURITY.md) for reporting vulnerabilities.
